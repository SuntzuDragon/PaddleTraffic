# 🏓 PaddleTraffic

Welcome to **PaddleTraffic** – the go-to web app for finding open pickleball courts near you in real time! 🎯 Whether you're a seasoned player or just looking to pick up a paddle, PaddleTraffic helps you discover available courts, meet players, and plan your pickleball outings better than ever.

## 🚀 Getting Started (Quick Dev Setup)

Make sure you have **Node.js**, **Python 3.10+**, **Poetry**, and **MySQL** installed.

> Make sure your MySQL server is running and the database is set up per backend instructions.

---

## 🌐 What is PaddleTraffic?

PaddleTraffic is a **real-time pickleball court locator** 🗺️ that:

- Crowdsources data from QR-code check-ins 📱
- Uses map pins with activity heatmaps 🔥
- Lets players form groups & host events 🧑‍🤝‍🧑
- Forecasts busy times using historical trends 📊
- Works great on mobile (PWA support) 📲

You can read more in the full [📄 Design Document](./Design%20Document%20-%20PaddleTraffic.pdf).

## 🛠️ Tech Stack

- **Frontend:** Vue.js, MapBox, Cypress (e2e)
- **Backend:** Django, Django REST Framework, Poetry
- **Database:** MySQL
- **Hosting:** AWS
- **CI/CD:** GitLab Pipelines
- **Bonus:** Progressive Web App features
